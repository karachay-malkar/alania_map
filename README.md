# Alan Map 7.0.25

Интерактивная 3D-карта Alan Til на MapLibre GL JS. Рабочая область физически обрезана до bbox `[40.95, 42.95, 43.55, 44.35]`: запад 40.95°E, восток 43.55°E, юг 42.95°N, север 44.35°N. Охват сохраняет ключевые районы карты и включает Черкесск с окрестностями. Север визуально ориентирован вниз (bearing 180°); географические координаты остаются стандартными.

3D-рельеф: Copernicus DEM GLO-30. Дороги, реки, водоёмы, residential, ледники/снег и вершины: локальный OpenStreetMap/Geofabrik PMTiles. Copernicus CLMS LCM-10 подключается при наличии CDSE OAuth credentials; без них используется OSM forest fallback.
