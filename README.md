# Alan Map 7.3.3

Версия 7.3.3 завершает трёхуровневую оптимизацию DEM. География карты, снег, ледники, реки, дороги, леса, населённые пункты, подписи, иконки, рамка, маска и компас не изменяются.

## DEM 7.3.3

Production-архив `data/alan-dem-7.3.3.pmtiles` физически содержит только три уровня высот:

- Z7 — низкая детализация, ≈442.574 м на информационный пиксель;
- Z9 — средняя детализация, ≈221.287 м на информационный пиксель;
- Z10 — высокая детализация, ≈110.644 м на информационный пиксель.

Физического Z8 в архиве нет. На масштабе карты Z8 используется overzoom Z7. От Z10 до максимального масштаба Z14.3 используется overzoom Z10. Высоты остаются квантованными с шагом 1 м, а сохранённые Z7/Z9/Z10 побайтово проверяются относительно DEM 7.3.2.

## Переходы между LOD

`assets/dem-lod-7.3.3.js` использует три runtime-источника одного PMTiles-архива. Переключение terrain выполняется только после завершения zoom-жеста, а перед переключением видимые тайлы следующего LOD прогреваются через тот же PMTiles Range-кэш. Для границ Z9 и Z10 добавлен небольшой hysteresis, чтобы исключить многократные переключения при колебании масштаба около порога.

Целевая схема:

- Z7–Z8 → native Z7;
- Z9 → native Z9;
- Z10–Z14.3 → native Z10.

## Первый запуск

Сохраняются оптимизации 7.3.2: параллельная загрузка runtime-скриптов без `eval`, компактный стартовый пакет данных, отложенные районные текстуры и точечные объекты, deferred snow source, HTTP Range-запросы PMTiles и ограниченный LRU-кэш.

Канонический снег остаётся `data/alan-snow-7.3.1.pmtiles`. Векторный архив остаётся `data/alan-vector-7.2.pmtiles`.
