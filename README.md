# Alan Map 12.1 — горные цепи и речные ущелья

Автономная плоская Slippy Map территории Карачаево-Балкарии и Нальсаны в утверждённой рабочей границе.

## Результат 12.1.4

- полная исходная база сохранена: 3797 горных объектов;
- активная база: ровно 1000 равномерно отобранных координат;
- все 1000 активных координат имеют фигурки из проектного PNG-атласа;
- фигурки присутствуют с общего масштаба и увеличиваются вместе с картой;
- текущая физическая ширина каждой категории увеличена ровно в 2 раза относительно 12.1.3;
- географическая координата проходит через центр полного PNG, а не через его вершину;
- фигурки объединены в один некликабельный custom WebGL layer;
- точечный MapLibre source, скрытые circle layers, карточка объекта и экранный hit-test удалены;
- основные горы и пятитысячники имеют повышенный размер и рисуются поверх обычных объектов;
- обычные объекты рисуются с севера на юг;
- поверх фигурок проложены 32 проверенные речные системы: 31 отдельная геометрия и Уллукам, представленный верхним руслом Кубани;
- безымянные и общие ручьи в активный речной слой не включены;
- реки рисуются широким фоновым коридором и более узкой синей линией;
- карта остаётся строго плоской: без DEM, terrain, hillshade, перспективы и вращения.

## Состав активной базы

- горы — 537;
- скалы — 236;
- холмы — 202;
- основные горы — 21;
- пятитысячники — 4;
- хребты — 0, поскольку в исходной точечной базе отдельные объекты этого типа отсутствуют.

## Формирование цепей

`tools/build_stage_12_1.py` проверяет каждую активную координату относительно ближайшего участка реки и соседних объектов. Для крупных разрывов используются три точечных коррекции:

1. увеличение `icon_scale` соседних фигурок;
2. выбор более широкого PNG внутри допустимой группы типа;
3. `base_shift` — слабый горизонтальный наклон изображения относительно его центра.

Расчёт записывается в:

- `data/mountains/selection_report.json`;
- `data/hydrography/river_mountain_report.json`.

## Привязка фигурок

`data/mountains/mountain_icon_bindings.json` содержит:

```text
point_id
icon_id
min_zoom
icon_scale
base_shift
priority
```

Все 1000 записей имеют `min_zoom = 6.7`. Физическая ширина вычисляется из типа объекта и `icon_scale`, затем переводится в единицы Mercator. Базовые ширины версии 12.1.4:

- гора — 16 000 м;
- скала — 15 200 м;
- хребет — 17 200 м;
- холм — 15 200 м;
- основная гора — 20 000 м;
- пятитысячник — 24 000 м.

При увеличении zoom на один уровень экранная ширина удваивается. Координата объекта остаётся в центре изображения на любом масштабе.

## Речные данные

Источник — локальный автономный OSM PMTiles Alan Map 7.0.23. Из него извлечены только системы, прошедшие прежнюю проверку полноты и непрерывности:

- 11 основных рек;
- 10 средних рек;
- 10 малых значимых рек;
- Уллукам учитывается через верхнее главное русло Кубани.

Активные файлы:

- `data/hydrography/rivers-major.geojson`;
- `data/hydrography/rivers-medium.geojson`;
- `data/hydrography/rivers-minor.geojson`;
- `data/hydrography/river_source_report.json`;
- `data/hydrography/river_mountain_report.json`.

## Порядок слоёв

1. фон;
2. заливка и граница территории;
3. 1000 PNG-фигурок;
4. фоновые коридоры рек;
5. линии рек;
6. будущие населённые пункты и подписи.

## Рендеринг

- один PNG-атлас `assets/mountains/mountain-atlas.png`;
- один custom WebGL layer `mountain-images`;
- 1000 прямоугольников, 6000 вершин в одном статическом vertex buffer;
- один draw call на кадр;
- изображения и исходные координаты не участвуют в hit-testing;
- удалён цикл проекции 1000 точек при каждом движении указателя;
- `mount-1` исключена;
- `mount-11` используется только для пятитысячника.
