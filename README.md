# Alan Map 12.1 — этап 1

Чистая автономная 2D Slippy Map для территории Карачаево-Балкарии и Нальсаны в ранее утверждённой рабочей границе.

## Состав этапа

- плоская однотонная основа;
- рабочая граница территории;
- все доступные горные объекты точками;
- категории: гора, скала, хребет, холм, основная гора, пятитысячник;
- карточка точки содержит только ID, тип, координаты, высоту и разрешённое название.

## Архитектура

Активная карта написана заново и использует только:

- `index.html`;
- `styles.css`;
- `src/config.js`;
- `src/data.js`;
- `src/map.js`;
- `src/app.js`;
- локальные части MapLibre;
- `data/map-frame.geojson`;
- `data/mountains/mountain_points.geojson` как исходную точечную базу.

Исходные точки при загрузке нормализуются до полей:

```text
id
type
longitude
latitude
elevation_m
name
```

Названия сохраняются только для основных гор и пятитысячников. ID формируются независимо внутри каждой категории: `mount-*`, `rock-*`, `ridge-*`, `hill-*`, `mount-main-*`, `mount-5000-*`.

## Ограничения этапа

Нет DEM, terrain, hillshade, PMTiles, перспективы, наклона, вращения, рек, дорог, населённых пунктов, лесов, PNG-гор и подписей.
