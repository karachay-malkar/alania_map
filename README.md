# Alan Map 7.2

Интерактивная 3D-карта Alan Til на MapLibre GL JS. Рабочая область — повёрнутый прямоугольник по четырём углам: [40.517840, 43.412650], [43.731622, 42.734095], [44.184003, 43.856420], [40.970221, 44.534975]. Технический envelope: `[40.51784, 42.734095, 44.184003, 44.534975]`; центр: `[42.350921, 43.634535]`. Геометрия, векторные слои и визуальная композиция унаследованы без изменения от 7.1.

Версия 7.2 переводит локальные PMTiles с крупных shard-загрузок на HTTP Range: браузер получает только требуемые диапазоны DEM и vector архивов. DEM остаётся одной визуально непрерывной 3D-поверхностью, но хранится как стандартная многоуровневая пирамида z7–z12; MapLibre выбирает нужный LOD по масштабу без отключения слоёв. После остановки камеры четыре соседних тайла тихо прогреваются в idle-время и попадают в ограниченный RAM-кэш диапазонов.

Рельеф Copernicus DEM GLO-30 физически обрезан по mapFrame, высоты квантованы до 1 м. Полностью заполненные DEM-тайлы сохраняются как RGB PNG, пограничные/NoData — как RGBA PNG; PNG кодируются lossless с максимальной zlib-оптимизацией. Никакие подписи, леса, реки или декоративные слои не скрываются во время движения карты.
