# Alan Map 7.3.2

Версия 7.3.2 объединяет оптимизацию первого запуска карты с новой трёхуровневой схемой загрузки DEM. География карты, снег, ледники, реки, дороги, леса, населённые пункты, подписи, иконки, рамка, маска и компас не изменяются.

## DEM 7.3.2

Runtime карты использует только три уровня информации из проверенного `data/alan-dem-7.3.pmtiles`:

- Z7 — низкая детализация, ≈442.574 м на информационный пиксель; используется на масштабах Z7–Z8;
- Z9 — средняя детализация, ≈221.287 м на информационный пиксель; используется на Z9;
- Z10 — высокая детализация, ≈110.644 м на информационный пиксель; используется от Z10 до Z14.3.

На Z8 отдельный DEM-запрос запрещён: MapLibre получает источник с `maxzoom: 7` и overzoom-ит Z7. Поэтому переход Z7 → Z8 не загружает новый набор высот. На Z9 подключается отдельный источник с `minzoom/maxzoom: 9`, на Z10 — источник с `minzoom/maxzoom: 10`; после Z10 новые DEM-уровни не запрашиваются.

Сам PMTiles-контейнер сохранён от проверенной 7.3.1, поэтому физические Z8-тайлы остаются внутри файла как неиспользуемые данные. Они недоступны runtime-схеме 7.3.2 и не участвуют в сетевой загрузке карты. Это решение не требует повторной генерации высот и сохраняет геометрию и 1-метровую квантовку 7.3.1 без изменений.

`assets/dem-lod-7.3.2.js` создаёт три raster-dem источника, синхронизирует hillshade с тем же LOD и переключает terrain только при переходе через границы Z9 и Z10.

## Первый запуск

Сохраняются ранее выполненные оптимизации 7.3.2: MapLibre и данные загружаются обычными JS-файлами без `fetch + concatenate + eval`; стартовый пакет данных сокращён; текстуры районных названий и точечные объекты загружаются отложенно; snow PMTiles регистрируется после первого idle либо при непосредственной необходимости; PMTiles используют Range-запросы и ограниченный кэш.

Канонический снежный слой остаётся `data/alan-snow-7.3.1.pmtiles`. Векторный архив остаётся `data/alan-vector-7.2.pmtiles`.
