# Alan Map 7.2.2

Интерактивная 3D-карта Alan Til на MapLibre GL JS. Рабочая область — повёрнутый прямоугольник по четырём углам: [40.517840, 43.412650], [43.731622, 42.734095], [44.184003, 43.856420], [40.970221, 44.534975]. Технический envelope: `[40.51784, 42.734095, 44.184003, 44.534975]`; центр: `[42.350921,43.634535]`.

База данных, рельеф, PMTiles, реки, подписи, навигация, пользовательское состояние и остальные рабочие слои сохранены от 7.2. HTTP Range, DEM LOD z7–z12 и ограниченный RAM-кэш работают без изменений.

## 7.2.2-r2 — native map-scene presentation

Рамка, пергаментная угловая маска и компас больше не используются как видимые SVG-оверлеи поверх WebGL-карты. Новый слой `map-presentation-r2.js` подавляет старые SVG-элементы и строит декоративную композицию один раз в географических координатах как GeoJSON, после чего добавляет её непосредственно в style MapLibre отдельным native source/layers.

- рамка привязана к точному `mapFrame`; её мировая ширина — 2000 м;
- орнамент рамки рассчитывается один раз в мировой геометрии с шагом 4800 м;
- маска использует исходные географические опорные точки 7.2 и ту же рваную внутреннюю кромку;
- компас собран из world-space polygon/line geometry с радиусом 22000 м, включая стрелки, кольца и буквы сторон света;
- видимые `parchment-overlay` и `map-perimeter-frame` удаляются, а новая композиция не использует `map.project()` или SVG matrix/translate/scale;
- камера MapLibre трансформирует карту, рамку, маску и компас единым pipeline, поэтому их взаимное положение не меняется при zoom/bearing/pitch.
