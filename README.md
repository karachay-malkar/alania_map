# Alan Map 7.3.1

Версия 7.3.1 остаётся в той же ветке и сохраняет рельеф 7.3. Снежное отображение переведено на постоянные векторные контуры, полученные из наиболее полного дальнего уровня z7 существующих snow PMTiles. Геометрия сглажена в метрических координатах и встроена непосредственно в map-data. Поэтому площадь и форма снега больше не меняются при переключении zoom-уровней, а края отрисовываются MapLibre как антиалиасинговые векторные границы.

Snow PMTiles 7.2.5 сохранены как исходные данные и для воспроизводимости, но больше не регистрируются как runtime network sources. Это также устраняет ошибки snow-permanent/snow-seasonal в сетевой диагностике. DEM 7.3 и vector 7.2 не изменялись.
