# Alan Map 7.3.2

Версия 7.3.2 ускоряет первый запуск карты без изменения геометрии DEM, векторного слоя или канонического снега.

Стартовый runtime больше не собирает MapLibre и данные через `fetch + concatenate + eval`. Браузер получает обычные JS-файлы параллельно с сохранением порядка исполнения. В первом пакете `assets/map-data-core.js` оставлены только данные, необходимые до первого кадра. Текстуры районных названий загружаются после первого кадра из `assets/map-data-deferred.js`, а точечные объекты населённых пунктов, перевалов и локальных пиков — отдельно из `assets/map-data-points.js` при приближении к Z10.

Snow PMTiles регистрируется после первого idle либо раньше, если карта сразу открыта на масштабе, где снег видим. На мобильных устройствах, при `Save-Data` и медленных 2G/3G-профилях отключена аварийная загрузка целого векторного PMTiles; остаются только Range-запросы с повторными попытками. Фоновый prefetch начинается только после первого idle.

Картографические архивы не пересобирались: `data/alan-dem-7.3.pmtiles`, `data/alan-vector-7.2.pmtiles` и `data/alan-snow-7.3.1.pmtiles` должны быть побайтово идентичны версии 7.3.1.

Канонический snow-layer остаётся `data/alan-snow-7.3.1.pmtiles`. Его физический архив содержит Z8–Z13; runtime использует Z8–Z12 и далее overzoom Z12, чтобы сохранить принятую форму снежного покрытия на близких масштабах.
