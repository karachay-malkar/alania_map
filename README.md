# Alan Map 12.1 — 1000 точек и выборочные фигурки

Автономная плоская Slippy Map для территории Карачаево-Балкарии и Нальсаны в утверждённой рабочей границе.

## Результат

- исходная база: 3797 горных объектов;
- активная база: ровно 1000 равномерно отобранных объектов;
- обязательные объекты сохранены полностью: 4 пятитысячника и 21 основная гора;
- фигурки назначены 300 точкам;
- все основные горы и пятитысячники имеют фигурки;
- остальные фигурки распределены пространственно и появляются по уровням масштаба;
- карта остаётся строго плоской: без DEM, terrain, hillshade, перспективы и вращения.

## Состав активной базы

- горы — 537;
- скалы — 236;
- холмы — 202;
- основные горы — 21;
- пятитысячники — 4;
- хребты — 0, поскольку в исходной точечной базе отдельные объекты этого типа отсутствуют.

Каждая активная точка содержит только:

```text
id
type
longitude
latitude
elevation_m
name
```

Названия сохранены только у основных гор и пятитысячников.

## Привязка фигурок

Файл `data/mountains/mountain_icon_bindings.json` не дублирует координаты. Каждая запись содержит:

```text
point_id
icon_id
min_zoom
icon_scale
priority
```

Координаты фигурки берутся из активной точки по `point_id`.

Фигурки распределены по непересекающимся наборам:

- пятитысячники — высокогорные массивные формы;
- основные горы — крупные выразительные формы;
- обычные горы — стандартные горные силуэты;
- скалы — наиболее острые формы;
- хребты — вытянутые формы;
- холмы — низкие формы.

`mount-1` исключена. `mount-11` разрешена только пятитысячникам.

## Масштабное появление

- 25 обязательных фигурок — с общего масштаба;
- 75 высокоприоритетных — с `zoom 8.2`;
- 100 средних — с `zoom 9.6`;
- 100 детальных — с `zoom 11.0`.

MapLibre дополнительно предотвращает наложения через встроенное размещение символов и приоритеты.

## Файлы данных

- `data/archive/mountain_points_full.geojson` — полный нормализованный набор 3797 точек;
- `data/mountains/mountain_points.geojson` — активные 1000 точек;
- `data/mountains/mountain_icon_bindings.json` — 300 привязок;
- `data/mountains/mountain_icon_catalog.json` — распределение PNG по типам;
- `data/mountains/mountain_icon_manifest.json` — координаты фигурок в атласе;
- `assets/mountains/mountain-atlas.png` — атлас из PNG проекта;
- `tools/build_stage_12_1.py` — воспроизводимая сборка отбора и привязок.
