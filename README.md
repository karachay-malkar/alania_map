# Alan Map 12.1.5 — горные цепи и речные ущелья

Автономная плоская Slippy Map территории Карачаево-Балкарии и Нальсаны в утверждённой рабочей границе.

## Результат 12.1.5

- сохранена полная исходная база из 3797 горных объектов;
- активная база содержит ровно 1000 координат и 1000 PNG-фигурок;
- 944 объекта взяты из исходной базы, 56 безымянных объектов `ridge` добавлены как технические якоря непрерывных хребтов;
- все основные горы и четыре пятитысячника сохранены;
- координата каждого PNG проходит через геометрический центр изображения;
- фигурки остаются некликабельными и рисуются одним WebGL-вызовом;
- физические базовые размеры ×2 относительно 12.1.3 сохранены;
- в плотных кластерах применяется только локальное уменьшение `icon_scale`;
- реки и фоновые коридоры рисуются поверх фигурок;
- карта не использует DEM, terrain, hillshade, наклон или вращение.

## Непрерывность цепей

`tools/build_stage_12_1.py` объединяет фрагменты каждой речной системы в маршруты и вводит станционирование — расстояние вдоль русла.

Для каждого поддерживаемого горного участка отдельно проверяются левый и правый борта долины. Допустимый максимальный продольный интервал:

- основные реки — 6,5 км;
- средние — 7,0 км;
- малые значимые — 7,5 км.

Когда в полной базе нет точки в требуемом интервале, генератор создаёт безымянный `ridge`-якорь. Он ставится параллельно проверенной речной геометрии на стороне существующей горной цепи и не обозначает вымышленную вершину.

Контрольные показатели записываются в:

- `data/hydrography/river_mountain_report.json`;
- `data/mountains/selection_report.json`.

Ключевые максимальные интервалы после пересборки:

- Черек Балкарский — 6,315 км;
- Черек Безенгийский — 6,462 км;
- Кубань — 6,094 км;
- Теберда — 6,444 км;
- Малка — 6,395 км;
- Чегем — 6,218 км;
- Баксан — 6,190 км;
- Большой Зеленчук — 6,006 км.

## Фигурки

- `mount-1` исключена;
- `mount-11` используется только для пятитысячника;
- все четыре пятитысячника используют разные PNG с ролью `peak`;
- основные горы и пятитысячники рисуются после обычных объектов;
- обычные объекты и `ridge`-якоря рисуются с севера на юг.

Базовые физические ширины не изменены относительно 12.1.4:

- гора — 16 000 м;
- скала — 15 200 м;
- хребтовый якорь — 17 200 м;
- холм — 15 200 м;
- основная гора — 20 000 м;
- пятитысячник — 24 000 м.

## Runtime

В браузере загружаются только версионированные файлы:

- `assets/maplibre-12.1.5.js`;
- `assets/app-12.1.5.js`;
- `assets/maplibre-12.1.5.css`;
- `styles-12.1.5.css`;
- `assets/mountains/mountain-atlas-12.1.5.png`;
- `data/map-frame-12.1.5.geojson`;
- `data/mountains/mountain-render-12.1.5.geojson`;
- `data/mountains/mountain-icon-manifest-12.1.5.json`;
- `data/hydrography/rivers-12.1.5.geojson`.

Runtime-`eval` удалён. Точки и привязки объединены в один готовый render-файл. Карта ограничивает внутренний pixel ratio значением 1,5 для снижения нагрузки на мобильных устройствах.
