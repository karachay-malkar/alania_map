# Alan Map 7.2.2

Интерактивная 3D-карта Alan Til на MapLibre GL JS. Рабочая область — повёрнутый прямоугольник по четырём углам: [40.517840, 43.412650], [43.731622, 42.734095], [44.184003, 43.856420], [40.970221, 44.534975]. Технический envelope: `[40.51784, 42.734095, 44.184003, 44.534975]`; центр: `[42.350921, 43.634535]`.

База данных, DEM/vector PMTiles, LOD z7–z12, прикладная логика, навигация и сохранение состояния остаются от проверенной версии 7.2.

## 7.2.2-r5 — granite frame + stable edge presentation

Гранитная основа `assets/map-granite-frame.js` остаётся статическим native MapLibre custom WebGL layer в world-space. Она строится один раз по географическому `mapFrame`, имеет верх +4000 м и низ −4000 м и не использует screen-space SVG, `map.project()` или отдельный animation loop.

Компас теперь позиционируется не старым процентным смешиванием трёх точек, а через геометрический safe-area: центр находится на внутренней биссектрисе угла с минимальным world-space отступом 34 км от двух прилегающих сторон. Пергаментная маска строится по тем же world-space опорным точкам и расширена так, чтобы полностью содержать компас вместе с N/S/E/W.

DEM получает скрытый 4.5 км edge-collar под гранитной рамой. В пограничной полосе ближайшая корректная Terrain-RGB высота продолжается наружу вместо мгновенного перехода к технической высоте −10000 м. Количество новых тайлов ограничено только узкой полосой вокруг существующей физически обрезанной поверхности.

## Mobile / PMTiles

`openmaptiles` использует адаптивный HTTP Range transport. На touch/mobile ограничено число параллельных vector Range-запросов, увеличен retry/backoff, а после устойчивого сетевого отказа текущий запрос автоматически переключается на один полный локальный буфер `alan-vector-7.2.pmtiles` (архив около 16.9 MB). Переинициализация всей карты не требуется, поэтому дороги, реки, леса, снег, ледники и остальные vector-слои могут восстановиться внутри того же PMTiles source.

Диагностика PMTiles сохраняет HTTP status, byte range, текст последней ошибки, число retry, активную concurrency и состояние full-file fallback. На мобильных соседний prefetch по-прежнему отключён.

CI проверяет runtime-contract, world-space геометрию, восстановление `openmaptiles` после искусственных 503, положение компаса, granite renderer и browser smoke-тест. Отдельный workflow материализует DEM edge-collar, проверяет размер архива и только после прохождения тестов записывает обновлённый DEM в `7.2.2`.
