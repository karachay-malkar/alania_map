# Alan Map 7.3.1

Версия 7.3.1 основана на полном состоянии 7.3 и меняет только способ отображения снежных слоёв.

Постоянный и сезонный снег больше не усиливаются по opacity при приближении и не переключаются вплоть до самого детального снежного уровня. Для отображения используется стабильный сглаженный контур: snow PMTiles визуально замораживаются на z10, а далее overzoom-ятся с linear resampling. Это сохраняет более полный дальний силуэт снега и убирает резкое сужение снежных пятен на близком масштабе.

DEM 7.3, vector 7.2 и сами snow-архивы 7.2.5 не пересобирались и не изменялись по байтам; изменены только runtime-настройки и метаданные релиза.
