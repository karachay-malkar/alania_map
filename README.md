# Alan Map 7.0.23

Автономная карта Alan Til для GitHub Pages. DEM и вектор физически обрезаны по рабочему контуру. Озёра, ледники, постоянный снег, речная сеть и вершины берутся из локального OSM PMTiles.

Версия 7.0.23 использует версионированные фрагменты PMTiles, ограниченный LRU-кэш, строгую классификацию водных объектов и топологическую сборку обязательных речных систем.
