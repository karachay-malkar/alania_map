# Alan Map 10.0 — плоская горная основа

- Все вершины извлечены из автономного слоя `peak` версии 7.0.23, включая безымянные точки.
- Основная таблица: `data/mountains/mountain_points.csv` — 7 столбцов.
- Главные вершины отмечены `category=main`.
- Используются `mount-2`—`mount-30`; `mount-1` исключена.
- `mount-11` разрешена только для точек от 4000 м.
- Карта плоская, без DEM, hillshade, дорог, подписей и 3D.
