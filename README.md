# Alan Map 7.0.21

Интерактивная карта Alan Til для GitHub Pages.

- Рельеф и векторные данные хранятся в репозитории.
- DEM и вектор физически обрезаны по рабочему контуру карты.
- Внешние картографические CDN не используются.
- Большие PMTiles разбиты на фрагменты; браузер читает их прозрачно по требуемым диапазонам.

Источник публикации: версия 7.0.21.
