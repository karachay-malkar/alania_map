# Alan Map 7.2.4

Интерактивная 3D-карта Alan Til на MapLibre GL JS. Рабочая область — точный повёрнутый прямоугольник по четырём углам: `[40.517840, 43.412650]`, `[43.731622, 42.734095]`, `[44.184003, 43.856420]`, `[40.970221, 44.534975]`. Технический envelope: `[40.51784, 42.734095, 44.184003, 44.534975]`; центр: `[42.350921, 43.634535]`.

## 7.2.4-r2 — районные названия и аудит названий населённых пунктов

Все 16 названий районов используют единый физический кегль по эталону `ÇEGEM`. Масштаб уменьшен ровно на 20%: с `0.666667` до `0.533334`. По пользовательской разметке переориентированы `BASXAN`, `DOMMAY`, `ARXIZ`, `SXAWAT` и `NARSANA`. Добавлены историко-географические названия `GİTÇE QARAÇAY`, `CÖGETEY` и `ZELENÇUK`; основание размещения хранится прямо в свойствах каждой подписи.

На карту добавлены 532 именованных узла, помеченных в снимке OpenStreetMap от `2026-08-15T06:05:02Z` как `city`, `town`, `village` или `hamlet` и попавших внутрь точной повёрнутой рамки: 5 городов, 28 посёлков городского типа/малых городов, 298 сёл и 201 малое поселение. Узлы `isolated_dwelling` и пять объектов с `population=0` исключены. Полный проверяемый отчёт находится в `data/settlement-catalog-7.2.4.json`.

Названия сразу выводятся аланской латиницей. 62 ранее утверждённых написания перенесены из 7.2.3, два местных названия закреплены отдельно (`CÖGETEY`, `CAÑGI CÖGETEY`), 22 взяты из OSM `name:krc`. Все прежние 446 автоматических транслитераций прошли воспроизводимую проверку по профилю аланской латиницы: у 439 записей есть связанный Wikidata/Wikipedia-объект, ещё семь сверены по независимым ссылкам. Теперь все 532 записи имеют `name_review_status: completed` и `name_review_required: 0`; полный построчный реестр — `data/settlement-name-review-7.2.4.json`.

Проверка названия не выдаётся за подтверждение местного эндонима, этнического состава или официального статуса поселения. Для `Зольская`, `Агурапста` и `Кельди` отдельно сохранён `active_status_review_required: 1`: написание проверено, но актуальный населённый/административный статус нужно сверить с профильным реестром. У всех записей `ethnographic_profile_status: pending`.

Сборка и повторная проверка каталога:

```bash
python tools/release_7_2_4.py build --settlements /path/to/osm-settlements-bbox.json
python tools/release_7_2_4.py review-names
python tools/release_7_2_4.py validate
```

## Сохранённые исправления рамки 7.2.3

Гранитная основа остаётся статическим native MapLibre custom WebGL layer в world-space: верх `+4000 м`, низ `−4000 м`. Пергаментная маска сохраняет геометрию 7.2, а компактный компас имеет независимый центр `[43.82900045, 43.71487991]` и радиус `14 300 м`.

DEM сохраняет скрытый edge-collar `4500 м`. Во внутренней полосе `900 м` и на внешней опоре высота ограничивается максимумом `+1000 м`; после внешней кромки `3200 м` поверхность плавно уходит к технической отметке `−10000 м`. Эти параметры устраняют no-data треугольники, не позволяя горному рельефу прорезать гранитную рамку.

## Mobile / PMTiles

`openmaptiles` использует адаптивный HTTP Range transport. На touch/mobile ограничено число параллельных vector Range-запросов, включены retry/backoff и автоматический full-file fallback для локального `alan-vector-7.2.pmtiles` без переинициализации карты.

CI проверяет каталог 7.2.4, числовой профиль DEM, runtime-contract, одинаковую высоту и количество районных подписей, world-space геометрию, Range transport, granite renderer и browser smoke-тест. Полный артефакт собирается как `alan-map-7.2.4.zip` вместе с перечнем размеров файлов.
