# Alan Map 7.0.24

Лёгкая автономная 3D-карта Alan Til на MapLibre GL JS. Карта восстановлена до минимального прямоугольного охвата прежнего контура. Фэнтезийный рендер удалён. 3D-рельеф построен на Copernicus DEM GLO-30. Дороги, реки, водоёмы, residential, ледники/постоянный снег и вершины собираются из локального снимка OpenStreetMap. Copernicus CLMS LCM-10 подключается как локальный PMTiles растительности при наличии CDSE OAuth credentials; без них сохраняется OSM forest fallback.
