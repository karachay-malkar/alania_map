# Alan Map 8.0

Автономная плоская иллюстрированная карта Alan Til для GitHub Pages. География, населённые пункты, дороги, реки, озёра, ледники, снег и вершины остаются привязаны к физически обрезанным локальным данным версии 7.0.23.

Версия 8.0 заменяет процедурные группы гор на библиотеку из 30 отдельных прозрачных PNG. Фигурки подбираются по типу реального хребта: пологие, обычные, скальные, массивные и отроги. Точки размещаются плотными перекрывающимися цепями вдоль реальных осей хребтов; части одного хребта сшиваются без искусственных пустот. Иконки остаются вертикальными при повороте карты и увеличиваются экспоненциально вместе с масштабом, как элементы единой печатной карты.

В фэнтезийном режиме DEM, hillshade и технические линии хребтов не отображаются, наклон фиксируется на 0°. Эльбрус использует отдельную сверхмасштабную двухвершинную PNG-фигуру. При приближении продолжают раскрываться дороги, поселения и локальные объекты согласно существующим zoom-уровням.
