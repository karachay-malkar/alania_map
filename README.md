# Alan Map 7.0.23

Автономная карта Alan Til для GitHub Pages. DEM и вектор физически обрезаны по рабочему контуру. Озёра, ледники, постоянный снег, речная сеть и вершины берутся из локального OSM PMTiles. Вектор: 13956788 байт (+407156 к 7.0.21).

В версии добавлен включённый по умолчанию гибридный фэнтезийный режим: реальный DEM остаётся географической основой, а существующие оси хребтов используются для процедурных горных цепей, отрогов, штрихов склонов и бумажной картографической фактуры. Эльбрус отображается отдельным крупным двухвершинным массивом. Переключатель «Фэнтези» возвращает исходный точный стиль без перезагрузки карты.
