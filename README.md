# Alan Map 12.1 — географически масштабируемые фигурки

Автономная плоская Slippy Map территории Карачаево-Балкарии и Нальсаны в утверждённой рабочей границе.

## Результат

- полная исходная база сохранена: 3797 горных объектов;
- активная база: ровно 1000 равномерно отобранных точек;
- сохранены все 4 пятитысячника и 21 основная гора;
- 300 выбранных точек имеют фигурки из проектного PNG-атласа;
- все 300 фигурок присутствуют с общего масштаба;
- фигурки имеют размеры в метрах и увеличиваются вместе с картой;
- фигурки рисуются одним некликабельным WebGL-слоем;
- обычные точки гор, скал, хребтов и холмов отображаются серым;
- точки основных гор и пятитысячников сохраняют отдельное выделение;
- карта остаётся строго плоской: без DEM, terrain, hillshade, перспективы и вращения.

## Состав активной базы

- горы — 537;
- скалы — 236;
- холмы — 202;
- основные горы — 21;
- пятитысячники — 4;
- хребты — 0, поскольку в исходной точечной базе отдельные объекты этого типа отсутствуют.

## Привязка фигурок

`data/mountains/mountain_icon_bindings.json` содержит:

```text
point_id
icon_id
min_zoom
icon_scale
priority
```

Физическая ширина рассчитывается в runtime из типа объекта и `icon_scale`, после чего переводится в метры Mercator. Поэтому при увеличении zoom экранная ширина фигурки удваивается вместе с масштабом карты.

Координата вершины определяется автоматически по альфа-каналу каждого фрагмента атласа. Горная точка совмещается с верхней видимой вершиной рисунка, а не с его центром или основанием.

## Рендеринг

- один PNG-атлас `assets/mountains/mountain-atlas.png`;
- один custom WebGL layer `mountain-images`;
- 300 прямоугольников, объединённых в один vertex buffer;
- один draw call на кадр;
- изображения не участвуют в hit-testing и не открывают карточки;
- карточки открываются только через видимые точечные слои;
- порядок отрисовки: северные обычные объекты → южные обычные объекты → основные горы → пятитысячники.

`mount-1` исключена. `mount-11` разрешена только пятитысячникам.

## Файлы данных

- `data/archive/mountain_points_full.geojson` — полный набор 3797 точек;
- `data/mountains/mountain_points.geojson` — активные 1000 точек;
- `data/mountains/mountain_icon_bindings.json` — 300 географических привязок;
- `data/mountains/mountain_icon_catalog.json` — распределение PNG по типам;
- `data/mountains/mountain_icon_manifest.json` — области атласа; координаты вершин вычисляются при загрузке;
- `tools/build_stage_12_1.py` — воспроизводимая генерация отбора и физических размеров.
