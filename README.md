# Alan Map 7.3.1

Снежные слои возвращены к исходной raster-отрисовке версии 7.3. Основной permanent/seasonal snow снова читается напрямую из неизменённых PMTiles 7.2.5 и сохраняет исходную детальную форму на близком масштабе.

Поверх исходного снега добавлены только небольшие GeoJSON gap-patches, построенные по расхождениям родительского z11 и детального z12. Патч допускается только рядом с уже существующим z12-снегом, отдельный компонент ограничен 64 пикселями, а суммарное добавление ограничено 3.5% детальной маски. Глобального расширения, нового большого контура и сглаживания всей снежной площади нет.
