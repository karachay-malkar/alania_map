# Alan Map 7.0.23 · Hybrid Slippy Map

Автономная плоская интерактивная карта Alan Til на базе версии 7.0.23. DEM и вектор физически обрезаны по рабочему контуру; озёра, ледники, постоянный снег, речная сеть, дороги и вершины читаются из локальных PMTiles.

## Архитектура

- raster-dem и hillshade используются как плоская картографическая основа;
- векторные PMTiles и GeoJSON остаются интерактивными слоями;
- наклон, вращение и terrain extrusion отключены;
- север зафиксирован сверху;
- PNG-горы создаются из существующих точек `peaks`, `highPeaks` и горных объектов;
- слой гор вставляется непосредственно под точечные слои вершин и объектов;
- `mount-1` не загружается;
- `mount-11` назначается только вершинам с высотой не менее 5000 м.

Диагностика доступна в консоли через `ALAN_SLIPPY_HYBRID_DIAGNOSTICS()`.
