# Alan Map 7.0.25

Интерактивная 3D-карта Alan Til на MapLibre GL JS. Рабочая область задана повёрнутым прямоугольником по четырём углам: [40.517840, 43.412650], [43.731622, 42.734095], [44.184003, 43.856420], [40.970221, 44.534975]. Технический envelope тайлов: `[40.51784, 42.734095, 44.184003, 44.534975]`; центр: `[42.350921, 43.634535]`. OSM-векторы физически обрезаются по контуру рамки, а внешний участок DEM/envelope закрывается runtime-маской без CSS clip-path. Север визуально ориентирован вниз (bearing 180°); географические координаты остаются стандартными.

3D-рельеф: Copernicus DEM GLO-30. Дороги, реки, водоёмы, residential, ледники/снег и вершины: локальный OpenStreetMap/Geofabrik PMTiles. Copernicus CLMS LCM-10 подключается при наличии CDSE OAuth credentials; без них используется OSM forest fallback.
