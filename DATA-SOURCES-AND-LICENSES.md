# Источники данных и лицензии

- Вершины: автономный слой `peak` Alan Map 7.0.23, подготовленный из OpenStreetMap / Geofabrik, © OpenStreetMap contributors, ODbL.
- Реки: локальный слой `waterway` автономного PMTiles Alan Map 7.0.23, подготовленный из OpenStreetMap / Geofabrik, © OpenStreetMap contributors, ODbL. В активный GeoJSON включены 32 проверенные именованные системы; безымянные ручьи исключены.
- Хребтовые якоря: технические безымянные точки, построенные между существующими горными объектами по станционированным бортам проверенных речных долин. Они используются только для размещения PNG и не объявляются самостоятельными вершинами.
- Рабочий контур: географическая основа Alan Map 7.0.21–7.0.23.
- Визуальный движок: локальная сборка MapLibre GL JS, BSD-3-Clause.
- Горные PNG предоставлены владельцем проекта; `mount-1` не используется, `mount-11` ограничена пятитысячниками.
